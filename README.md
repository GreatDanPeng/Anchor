# ⚓ Anchor

Anchor is a Chrome extension that turns YouTube videos into a personal study notebook: organize videos into folders, generate AI notes and quiz cards, and chat with a tutor grounded in what you've collected — all for free, no setup required.

## What it does

- **Capture** — on any YouTube video, the popup lets you drop it straight into a folder (e.g. "AP Calculus Review"), creating the folder on the spot if needed. If the video is part of a playlist, add every video in it with one checkbox.
- **It prepares itself** — the moment you capture, notes and the folder's tutor knowledge base start building automatically in the background, one video at a time. No "Generate" button to click — by the time you open the notebook, it's usually ready to chat.
- **Notebook** — click the Anchor logo to open the full notebook page: browse your folders and each video's knowledge dataset (transcript + structured AI notes)
- **Quiz Cards** — turn a video's dataset into flashcards with one click; review them folder by folder
- **Teacher Mode** — chat with a tutor grounded strictly in everything you've added to a folder — attach your homework or resume and ask about a specific problem
- **Free by default** — notes/quiz/skills/chat are generated by Anchor's hosted backend using free OpenRouter models, no account needed. Power users can switch to their own Claude, DeepSeek, OpenAI, or OpenRouter key in Settings.

> ⚓ Anchor reads video **captions/subtitles**, not the video itself. Videos without captions can't be processed.

## Quick start (users)

```bash
cd chrome_extension
npm install
npm run build
```

Load `chrome_extension/dist` as an unpacked extension in `chrome://extensions` (enable Developer Mode). On any YouTube video, click the Anchor icon to add it to a folder, then click the Anchor logo to open the notebook — notes, quiz cards, and Teacher Mode chat prepare themselves automatically.

## Running the hosted backend (maintainers only)

Most users never need this — it's already deployed and the extension points at it by default. To run your own:

```bash
cd backend
npm install
cp .env.example .env   # add your own OPENROUTER_API_KEY
npm run dev
```

See [TECHNICAL.md](TECHNICAL.md) for the full architecture, data model, and how the free-model pool works.

## Tech stack

| Layer | Technology |
|---|---|
| Extension | React 18 · TypeScript · Vite (Manifest V3), two pages: popup + notebook |
| Transcript | Extracted client-side from YouTube's own page data (auto-opened background tab when needed) |
| Storage | `chrome.storage.local` — folders, videos, datasets, quiz cards, skills, chat history |
| PDF text extraction | `pdfjs-dist`, for Teacher Mode file attachments |
| Hosted backend | Node · TypeScript · Express — proxies to OpenRouter's free model pool |
| LLM (optional BYO key) | Claude, DeepSeek, OpenAI, or OpenRouter — called directly from the browser |
